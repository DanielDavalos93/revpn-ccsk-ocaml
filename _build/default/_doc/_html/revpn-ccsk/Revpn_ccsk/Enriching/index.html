type net_system = {
  1. net : Net.labelled_net;
  2. m : Token.markingTok;
}

A net system is a pair (N, m) with N labelled net and the marking m is a mapping associating to each place a multiset of tokens, i.e. m : S \to \mu\textsf{Tok}.

val make_net_system : Net.labelled_net -> Token.markingTok -> net_system
val immediate_transitions : Net.labelled_net -> (Net.transition * Net.transition) list

Immediate dependency. Two transitions t_1, t_2 are in immediate dependency if there is a place a \in P such that (t_1, a) \in R \wedge (a, t_2) \in R.

val is_enabled_tk : net_system -> Net.transition -> bool

is_enabled_tk tn tid checks if transition tid is enabled in the token net tn.

A transition tid with input places p1,…,pk is enabled iff the current marking token has label in p1,…,pk, i.e., the token currently sits in one of the input places.

val next_id : Token.Token.t -> int

next_id tk returns a fresh identifier = size of the token + 1.

val unopt_net_system : net_system option -> net_system
val fire_tk : net_system -> Token.markingTok -> Net.transition -> net_system option

fire_tk ns m tid fires tid consuming the tokens m ⊆ ns.m.

With w_s the token of m in s ∈ •t and w = (\lambda(t), \langle\!\langle w_{s_1},\dots,w_{s_n}\rangle\!\rangle, i):

m'(s) = \begin{cases}
      m(s) - w_s + w & s \in {}^\bullet t \cap t^\bullet \\
      m(s) - w_s     & s \in {}^\bullet t \setminus t^\bullet \\
      m(s) + w       & s \in t^\bullet \setminus {}^\bullet t \\
      m(s)           & \text{otherwise}
    \end{cases}

Returns None if m is not a valid choice of tokens for t.

val firing_sequence_tk : net_system -> Token.markingTok list -> Net.transition list -> net_system option

firing_sequence_tk tn ts fires all transitions in ts in order. Returns Some tn' if every step succeeds, None at first failure.

type keyPairNet = {
  1. net : Net.labelled_net;
  2. key : Net.place list;
}
val is_key_net : keyPairNet -> bool

Key Labelled Net. A net K = (N, S_k) is called key labelled net (or key net) if for every t \in T, |t^{\bullet} \cap S_k| = 1, and for all s \in S_k, such that |s^{\bullet}|=0 \wedge |{}^{\bullet} s|=1.

val keypl : keyPairNet -> Net.transition -> Net.place list

Let kn = (N, S_k) be a key labelled net and let t be a transition. Then with s^t we denote the key place s^t \in S_k such that {}^{\bullet} s^t = \{t\}. The key place associated to a transition t is denoted with \mathsf{keypl}(t). So, keypl kn t returns the key place associated to t.

val is_key_initial : keyPairNet -> Token.markingTok -> bool

We say that m is initial iff (a) \forall s \in S, [\![ m(s) ]\!] \subseteq \{(\cdot,\langle\!\langle \rangle\!\rangle, \cdot)\} and (b) \forall s \in S_k, m(s) = 0.

type reversing_net = {
  1. key_net : keyPairNet;
  2. rev_trans : Net.transition list;
}

Formally a reversible labelled net is a pair R=(N,S_k,U), where \mathsf{K} = (\langle S, T, F, \lambda, \mathsf{A}\rangle, S_k) is a key net, and U is the set of reversing transitions with U \subseteq T. We define reversing_net as a pair {key_net = kn; rev_trans = rt} being kn the key net \mathsf{K} and rt the reversing transitions set U.

val forwardTransition : reversing_net -> Net.transition list
val forwardKeyNet : reversing_net -> keyPairNet

forwardKeyNet rn: for every a reversible net rn equals to (N, S_k, U) with N = \langle S, T, F, \lambda, \mathsf{A}\rangle returns the forward key net (\langle S, T, F_f, \lambda\rangle, S_k) where F_f suprimes all the arcs (s, u) and (u, s) with u \in U over F.
