val is_enabled_tk : net_system -> Net.transition -> bool

Enabling and Firing for tokens

is_enabled_tk tn tid checks if transition tid is enabled in the token net tn.

A transition tid with input places p1,…,pk is enabled iff the current marking token has label in p1,…,pk, i.e., the token currently sits in one of the input places.

val fire_tk : net_system -> Token.markingTok -> Net.transition -> net_system option

fire_tk ns m tid fires tid consuming the tokens m ⊆ ns.m.

With w_s the token of m in s ∈ •t and w = (\lambda(t), \langle\!\langle w_{s_1},\dots,w_{s_n}\rangle\!\rangle, i):

m'(s) = \begin{cases}
      m(s) - w_s + w & s \in {}^\bullet t \cap t^\bullet \\
      m(s) - w_s     & s \in {}^\bullet t \setminus t^\bullet \\
      m(s) + w       & s \in t^\bullet \setminus {}^\bullet t \\
      m(s)           & \text{otherwise}
    \end{cases}

Returns None if m is not a valid choice of tokens for t.

val firing_sequence_tk : net_system -> Token.markingTok list -> Net.transition list -> net_system option

firing_sequence_tk tn ts fires all transitions in ts in order. Returns Some tn' if every step succeeds, None at first failure.
