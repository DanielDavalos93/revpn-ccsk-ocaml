Module Revpn_ccsk.Enriching

type token =
  1. | Tok_empty
  2. | Tok of Lts.label * token list * int

token is the set of tokens defined inductively as:

  • Tok_empty: (\cdot, \langle\!\langle \rangle\!\rangle, \cdot)
  • Tok (a, ls, i): if ls has token type, (a, \langle\!\langle w_1,\dots,w_n\rangle\!\rangle, i) with a an action, w_1,\dots,w_n are tokens and i\in\mathbb N an identificator number.

To take into account the new notion of tokens, we have to reformulate the notions for semantics. token_net is the type for nets where the markings have type token.

type token_net = {
  1. net : Net.labelled_net;
  2. marking : token;
}
val make_token_net : Net.labelled_net -> token -> token_net
val m : Net.marking -> token
val m_flat : Net.labelled_net -> Net.transition_id -> token

m_flat marking converts a marking into a flat token whose children are one Tok(p, [Tok_empty], i) per place, numbered left to right.

m_flat = Tok_empty m_flat p1;…;pn = Tok ("·", Tok(p1,[Tok_empty],1); Tok(p2,[Tok_empty],2); … Tok(pn,[Tok_empty],n), n+1)

val is_enabled_tk : token_net -> Net.transition_id -> bool

is_enabled_tk tn tid checks if transition tid is enabled in the token net tn.

A transition tid with input places p1,…,pk is enabled iff the current marking token has label in p1,…,pk, i.e., the token currently sits in one of the input places.

val next_id : token -> int

next_id tk returns a fresh identifier = size of the token + 1.

val fire_tk : token_net -> Net.transition_id -> token_net option

fire_tk tn tid fires transition tid if enabled.

Firing t with:

  • current token w = Tok (p, history, i) in input place p
  • output places q1, …, qk

Produces one new token per output place, each wrapping w: w'ⱼ = Tok (qⱼ, w, next_id w)

Since the marking is a single token, firing t with one output place produces Tok (q, [w], i+1).

For transitions with multiple output places (like t4 in Figure 3) we produce a combined token whose children are one token per output: w' = Tok (tid, Tok(q₁,[w],i+1); Tok(q₂,[w],i+2), i+1)

Returns None if tid is not enabled.

val unfire_tk : token_net -> Net.transition_id -> token_net option

unfire_tk tn tid reverses the firing of tid. If the current token is Tok (tid, [w], _), returns w. Returns None if the current token was not produced by tid.

val firing_sequence_tk : token_net -> Net.transition_id list -> token_net option

firing_sequence_tk tn ts fires all transitions in ts in order. Returns Some tn' if every step succeeds, None at first failure.

val key_net : Net.marked_net -> bool

Key Labelled Net A net K = (N, S_k) is called key labelled net (or key net) if for every t \in T, |t\bullet \cap S_k| = 1, and for all s \in S_k, |s\bullet|=0 \wedge |\bullet s|=1.
