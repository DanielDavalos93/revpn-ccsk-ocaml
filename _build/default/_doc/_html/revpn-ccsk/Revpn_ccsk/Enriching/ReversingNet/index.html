Module Enriching.ReversingNet

type reversing_net = {
  1. key_net : keyPairNet;
  2. rev_trans : Net.transition list;
}

Formally a reversible labelled net is a pair R=(N,S_k,U), where \mathsf{K} = (\langle S, T, F, \lambda, \mathsf{A}\rangle, S_k) is a key net, and U is the set of reversing transitions with U \subseteq T. We define reversing_net as a pair {key_net = kn; rev_trans = rt} being kn the key net \mathsf{K} and rt the reversing transitions set U.

val forwardTransition : reversing_net -> Net.transition list
val forwardKeyNet : reversing_net -> keyPairNet

forwardKeyNet rn: for every a reversible net rn equals to (N, S_k, U) with N = \langle S, T, F, \lambda, \mathsf{A}\rangle returns the forward key net (\langle S, T, F_f, \lambda\rangle, S_k) where F_f suprimes all the arcs (s, u) and (u, s) with u \in U over F.

val prop_reverse_transition : reversing_net -> Net.transition -> Net.transition -> bool

Let rn be a reversing net R =(\langle S, T, F, \lambda, \mathsf{A}\rangle, S_k, U). For each forward transition t in T and backward transition u in U, prop_reverse_transition rn u t is true if

({}^{\bullet}u=t^{\bullet}) \wedge (u^{\bullet}={}^{\bullet}t) \wedge (\lambda (t) = \lambda (u)).
val is_reversible_labelled_net : reversing_net -> bool

is_reversible_labelled_net take a reversing net R =(\langle S, T, F, \lambda, \mathsf{A}\rangle, S_k, U) as rn and returns true if it satisfies the following statements:

  1. rn.key_net.net has type labelled_net;
  2. If we write (\langle S, T \setminus U, F \setminus (\{(s, u) | s \in S, u \in U \} \cup \{(u, s) | s \in S, u \in U \}), \lambda, \mathsf{A}\rangle, S_k) as kn', then is_key_net kn' is true; and
  3. U \subseteq T and \forall u\in U, \exists! t\in T\setminus U, prop_reverse_transition rn u t.
val reverse_transition : reversing_net -> Net.transition -> Net.transition list

When rn : reversing_net satisfies the is_reversible_labelled_net def., then reverse_transition rn t returns the transition Some t', such that

({}^{\bullet}t=t'^{\bullet}) \wedge (t^{\bullet}={}^{\bullet}t') \wedge (\lambda (t) = \lambda (t')).

Of course, this condition is allways possible because of the third reversible condition. In otherwise, reverse_transition rn t returns None. In this function, don't mind if t is forward or backward transition.

val is_enabled : reversing_net -> Token.markingTok -> Net.transition -> bool

Let R = (\langle S, T, F, \lambda, A\rangle, S_k, U) be a reversible labelled net and let u \in U be a reversing transition, and t \in T \setminus U the corresponding forward transition. Then u is enabled at the marking m whenever

    \begin{align*}
    &\forall s \in {}^{\bullet}u,\\
    & \quad \exists w \in m(s), \mathsf{label}(w) = \lambda(t) \wedge \\
    & \qquad \forall w'\in \lfloor w \rfloor,\\
    & \quad \qquad \exists s' \in u^{\bullet},\\
    & \qquad \qquad \exists t' ∈ {}^{\bullet}s, 
        w′ \in m(\mathsf{keypl}(t)) \vee w′ = (\cdot, \langle\!\langle \rangle\!\rangle, ·)
    \end{align*}
