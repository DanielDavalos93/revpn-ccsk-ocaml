val exists_unique : 'a list -> ('a -> bool) -> bool

For a set x and a function f : x \to \mathsf{Bool}, exists_unique x f is equivalent to \exists! x, f(x), which its definition is \exists x, \left(f(x) \wedge \forall y, f(y) \Longrightarrow x = y\right).
